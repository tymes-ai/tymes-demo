# Design language: what you can click

The demo does not use the web's usual blue links, so it needs its own rules,
used the same way everywhere. A thing's look should say what it does.

## Clickable

Everything clickable reacts when the pointer is on it.

| Looks like | Is | Example |
| :--- | :--- | :--- |
| Dark filled box, with a verb | The main action | Buy 10 meetings, Continue |
| Dark outline, with a verb | A second action | Open a running campaign, Back |
| Underlined text | A link | Pick another goal |
| Outlined option, in a box or a boxed list | A choice | Meeting packs, goals, approval levels |
| Text in a tab bar | A tab | Promo code, Card, Settings tabs |

## Selected

**Mustard means selected, and nothing else.** The chosen pack, goal, or level
is mustard with a check mark. The current tab, the current page in the side
navigation, and the open conversation are mustard too.

## Not clickable

Everything else is flat and never reacts.

| Looks like | Is | Example |
| :--- | :--- | :--- |
| Bold text with a small colored square | A card header | What you pay for, Campaign ISP |
| Small grey label with a small colored square | A tag | Interested, Customer interviews |
| Plain text | A value | Uses 1 |
| Grey block with a dark bar on the left | A note | Ratings moved prospects |
| Large grey, dark, blue, or green block | A summary band | 18 meetings left in your pack |
| Thin bar and "Step 2 of 5" | Setup progress | The top of each setup step |

Color in a non-clickable thing is only a small marker, never a fill. A solid
dark box is always a button.

## Shapes

The square, triangle, half circle, and red circle are decoration. They mark a
phase or a choice next to its text, and are never the thing you click.

## When adding something

1. Can it be clicked? Use a button, a link, or an outlined choice.
2. Can it be selected? Make the selected one mustard, with a check mark on choices.
3. Otherwise, keep it flat: a label, a tag, or plain text.
